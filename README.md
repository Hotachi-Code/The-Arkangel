# The Arkangel

**Roguelike akciójáték PC-re:** az Arkangyal alászáll a Pokol hét gyűrűjén. Minden gyűrű egy főbűn, és mindegyik végén annak démona vár. A legalsó gyűrűben Lucifer, a **Kevélység** áll, amelyből minden más bűn fakad.

## Letöltés és indítás (telepítés nélkül)

1. Töltsd le a **`TheArkangel.html`** fájlt (GitHubon: a fájl megnyitása, majd *Download raw file*; vagy *Code → Download ZIP*).
2. Kattints rá duplán. Megnyílik a böngésződben (Chrome, Edge, Firefox), és már játszhatsz is.
3. Az **F** gombbal teljes képernyőre válthatsz.

Internet nem kell hozzá. Az egész játék egyetlen fájl.

## Irányítás

| Gomb | Művelet |
|---|---|
| **W A S D** | mozgás |
| **Bal egérgomb** (nyomva tartva) vagy **nyilak** | lövés szent fénnyel |
| **Space / Shift** | kitérés (közben sérthetetlen vagy) |
| **Q** / jobb egérgomb | Szent Nova, ha a Kegyelem-sáv megtelt (minden közeli démont sebez és eltörli a lövedékeket) |
| **E** | vásárlás a boltban |
| **Esc** | szünet és az áldásaid listája |
| **F** | teljes képernyő |
| **M** | hang ki/be |

## Roguelike elemek

- Minden futásnál véletlenszerűen generált termek és pályák.
- 20 féle **áldás** (fejlesztés): többes lövés, átható fény, követő lövedékek, őrző gömbök, szent láng, pajzs és még sok más.
- **Égi Oltár** (arany jel a térképen): 3 áldásból választhatsz egyet.
- **Bolt** (kék jel): lelkekért vásárolhatsz áldást vagy gyógyulást.
- Halál után minden elölről kezdődik. A legmélyebb elért gyűrűt a játék megjegyzi.
